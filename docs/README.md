# DigiBank Documentation

This folder contains the project documentation used by developers, reviewers, and graders.

## Folders

- `architecture/`: explains why DigiBank is a modular monolith and how the modules fit together.
- `api/`: summarizes the REST API and documentation endpoints.
- `modules/`: explains each Maven module and its responsibility.
- `operations/`: explains local development, Docker Compose, CI, and future deployment work.
- `security/`: explains DevSecOps controls and security decisions.
- `tickets/`: lists active follow-up tickets only.
- `archive/`: keeps completed plans and tickets as project history.
- `evidence/`: keeps workshop evidence and implementation notes.

## Reading Order

Start with `architecture/overview.md`, then read `modules/overview.md`, then use `api/endpoints.md` and `security/devsecops.md` for review details.
